# MicroJobs capstone demo script

Use isolated presentation accounts and seeded sample data. Confirm email delivery and device connectivity before presenting.

## Worker

1. Sign in and complete OTP.
2. Open Find Jobs at phone width, search/sort, open a listing, save it, and apply.
3. Show Applied Jobs, Saved Jobs, and Messages.
4. Trigger the prepared API-failure fixture and show the retry state.

## Employer

1. Switch to Employer and create a job, intentionally showing inline validation first.
2. Edit the job, review applications, change one stage, and run a prepared bulk update.
3. Schedule an interview, open messaging, then demonstrate the themed close/delete confirmation.

## Admin

1. Sign in through the admin route and open User Management at phone width.
2. Invite a standard worker account and show the normal sign-in flow without forced password replacement.
3. Edit a standard user’s identity, role, and status; show that privileged changes are server protected.
4. Review jobs, reports, and wallet monitoring, then demonstrate a destructive confirmation.

## Close

Show the five-width screenshot evidence, automated test results, bundle reduction, and the remaining `Runtime review` device/assistive-technology gates without claiming they are complete.
